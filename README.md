# Дринкит-4: дашборд поступления оборудования

Трекинг оборудования, мебели, света, электрики, сантехники, дверей, отделки и декора для кофейни Дринкит-4
(Якутск, ул. Дзержинского, 52/1). Проект: Орбита, DRKTYKTORB-1-4-АР.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Статичная копия **только для просмотра**. Открывается в любом браузере, в том числе на телефоне. Подходит для GitHub Pages |
| `source/dashboard-editable.html` | Рабочая версия с редактированием и загрузкой УПД. **Работает только внутри Claude** (сохранение и разбор документов завязаны на Claude), на хостинге вне Claude не запустится |

## Возможности

- Статусы: план, заказано, в пути (выезд и прибытие), на складе, в кофейне, закупает подрядчик
- Разделы: оборудование, мебель, освещение, электрика, сантехника, двери, отделка, декор и вывески
- Закупщик (Денис К. или подрядчик), транспортная компания, даты, суммы
- Раздел «Расходы»: товарные и транспортные документы с привязкой к УПД и товару
- Сортировка по всем колонкам, фильтры, поиск, мобильная версия

## Публикация через GitHub Pages

1. Settings -> Pages -> Source: Deploy from a branch -> ветка `main`, папка `/ (root)` -> Save
2. Через минуту страница откроется по адресу `https://<аккаунт>.github.io/<репозиторий>/`

## Обновление данных

`index.html` это снимок данных на момент выгрузки. Чтобы обновить, попросите Claude собрать новую копию для просмотра и замените файл `index.html`.

## Важно

В файлах есть суммы, поставщики и перевозчики. Публичный репозиторий и GitHub Pages открыты всем, у кого есть ссылка. Если данные не для посторонних, делайте репозиторий приватным.
